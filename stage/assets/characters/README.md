Put character art here as `<key>.png` (or .jpg / .jpeg / .webp), named after the character file in config/characters/
(ritika.png, imran.png, tiwari.png, chintu.png, bimla.png, ...).

Portrait orientation works best (about 4:5), face in the upper half. Until a file exists,
the show screen draws a placeholder in the character's colour.
